# 2.5.1 混合粘贴检查

日期：2026-10-09。该版本新增混合剪贴板与拖放；后端和模型提示词沿用 2.5。

- 输入框接收文字、图片和文件：文字插入光标位置，附件保存在该条草稿的 IndexedDB 中。
- 粘贴按钮优先读取完整剪贴板；旧浏览器没有读取接口时使用文字粘贴。
- HTML 只提取文字、安全链接和本地图片字节，不执行内容、不自动抓取外部图片。纯文件路径不放进通知正文。
- 图片显示缩略图并可预览；只有图片时提示补充文字。无法取得图片、单文件超过5 MB或总附件超限时保留可用文字并提示。
- 10个附件/每条20 MB限制沿用；只把正文发给模型，附件不同步云端。

免费检查：原有147项前端测试通过，新增25项剪贴板测试通过；类型检查和生产构建通过。真实 Chromium 的12个模拟场景通过（390×844手机、1280×800宽屏），覆盖混合内容、选区替换、HTML、图片单独粘贴、拖放、大文件及剪贴板按钮。一次分析请求使用模拟响应，已检查发送内容只有文字、保存后的附件归属和云同步不含附件。

这些测试没有调用真实模型或发送邮件，也没有使用用户浏览器的账号或资料。实际QQ复制能否提供完整图片/文件，取决于QQ与操作系统交给剪贴板的数据，尚未实测；若只提供图片地址、截图或文字，网页会保留得到的内容，不声称取回未提供的附件。Android真机剪贴板/系统权限仍需单独验证。

2.5的长通知首次公网SCHEMA_INVALID、资格遗漏、子步骤不稳定和截止指代关联问题仍未解决；本次剪贴板改动不代表这些模型问题已修复。上线、签名包和最终版本证据由仓库外的交付清单记录。
