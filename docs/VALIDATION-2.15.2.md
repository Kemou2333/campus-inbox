# 2.15.2 验证记录（2026-10-16）

引导遮罩此前只露出当前按钮，通知生成和操作结果仍被压暗。本版将阅读窗口与允许点击的控件分开：原文、卡片、展开步骤保持正常亮度，后续操作依然按步骤解锁。矮横屏提示随内容滚动，不挤掉通知标题。
