# 原文出处与人工修正

通知的每段整理文字旁有出处图标。点击后查看原文并高亮关联段，再从同一窗口进入「修正」。没有关联的旧记录不会凭空补出处；完整文字精确匹配仅标记「可能相关」，不代表核实。

新的 AI 整理使用程序生成的原文段号，`sourceRefs` 将字段路径关联至最多八段原文。程序校验字段确实存在、段号在当前原文范围内，位置由同一分段函数计算，不采用模型自报字符位置。模型可以给一个任务、步骤或时间节点的支持段号，由程序展开为每个文字字段的独立出处；个别句子可单独引用其他段并覆盖共用关联。关联仍由 AI 选择，必须人工对照，不能把有链接当成事实正确。

人工修正保存在独立的 `corrections` 层，原文与原 AI 字段完整保留。修改立即写入本机并进入已有云同步流程，不会重新调用模型。完成状态、步骤 ID、笔记、附件和手动提醒日期保留。可逐字段改标题、简介、任务对象/条件/说明/步骤、时间地点、材料、注意与提醒；本版不增删任务或步骤结构。漏项可以补进相关说明。恢复初稿移除修正层，保留最新进度和笔记。

缺少年份的时间不会自动借用原年份。已设置的本地提醒日期优先保留；修正通知文字不能替代对提醒日期的确认。备份和云同步保留原字段、出处及修正层。旧记录没有这些可选字段仍按原方式读取。
