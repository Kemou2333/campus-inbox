# 免费回归检查

本页列出的免费检查均使用本地假响应，不调用 DeepSeek，不消耗模型余额。后端测试使用注入的 modelFetch 和临时文件，不能影响实际服务配额。

## 可重复的单元测试

```sh
node --test tests/*.test.mjs
```

18 项检查覆盖：鉴权与来源、无效和过大请求、分钟限流、单请求并发、缓存、付费失败不自动重试、每日上限持久保存、北京时间跨日、损坏配额文件拒绝启动、UTF-8 字节限制、真实日历、结构化字段、旧版备份和排序。

GitHub Actions 在发布后端前运行全部单元测试。

## 本机浏览器检查

使用隔离浏览器和本地模拟接口，不读取实际用户的浏览器记录。

- 附件数量、单文件及总大小边界；空文件和 5 MB 文件完整往返恢复。
- SVG 仅作为下载附件，通知中的 HTML 与脚本保持为文字。
- 缺失、重复、损坏附件备份被拒绝；恢复使用新附件编号，保留文件字节。
- 浏览器存储配额失败时，旧通知保留，新暂存附件被清理。
- 空输入、访问码取消与失效、非 JSON 返回、次数限制、错误结构、断网与中止。
- 重复点击只发起一次请求；失败后保留原文，按钮恢复可用。
- 键盘切换标签；320、375、390、430、768、1024、1440 像素宽度无横向溢出。
- 首次使用教程、上一步/下一步、完成后不再自动弹出、帮助重开、Escape 关闭。
- 320×280 短视口弹窗在屏幕内滚动，最后一个按钮仍可操作。
- 4,000 字接受、4,001 字在前端拒绝且不发请求，旧 12,000 字备份仍可读取。
- 勾选保留卡片 DOM，更新进度不重播入场；详情过渡、弹窗过渡与减少动效生效。
- 手机表单字体至少 16 px，小图标按钮扩大触控区域。

修复了大附件 base64 校验使用分组重复正则时可能发生的 RangeError，并用连续字符校验与预分配字节数组降低恢复时的内存开销。时间节点的严格校验也与公开 JSON Schema 对齐；旧备份仍保留兼容读取。

这些检查验证界面、存储和费用保护，不替代真实模型的语义评估。
