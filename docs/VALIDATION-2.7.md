# 2.7 短通知速度与离开后保存验收

日期：2026-10-10。本文件记录发布前代码与本地检查，不证明已经上线。发布后的实际网页、后端和APK证据另见根HANDOFF及版本固定交付清单。默认仍使用low思考，一批一次模型请求，不自动收费重试，不人工修改自然响应。

## 提示词选择

一个输入来源且规范化正文长度不超过600（JavaScript字符串length）时使用r8精简提示；超过600或多个来源使用r6完整提示。r8要求直接摘录明示事实，以约100个思考token为一次必要短核对目标，立即输出完整JSON，不反复比较、复述规则、写分析草稿或润色。未知事实留空，结构和关键资格仍完整。

100个token是软提示目标，模型未提供对应独立硬限制。实际r8评教样本用了2371个思考token，不能宣称约束已把思考压到100个token，也不保证固定秒数。low仍保留32768完整生成上限，避免单纯压上限截断JSON。最终分支内容hash与已测r6/r8提示相同；600、601及多来源选择规则已免费检查，不额外调用模型审核。

短原文选自用户授权的本地办事簿Excel，正文直接使用对应原单元格，不重新编写。每个样本/版本组合只收一次自然首次响应；显式修改提示词后的实验分别计数。以下耗时是直接供应商API首个完整响应耗时，包含思考和输出，不是网页提交至云保存的端到端时间。

短通知的首次观察范围为4.470–17.183秒，总token为2749–5163，不能由长度单独推断固定速度。数学r7比r6更慢；评教r8比r7快约3.97秒，但缓存条件与供应商负载不同，均只是单次观察。在上述六次发布前实验中，最终r8短分支只真实测过评教；数学和英语考试未在这六次实验中使用最终r8实测。

r8长通知结构合法，保留部分关键资格和截止，但耗时62.129秒，比历史同原文r6的46.805秒更慢；原一张总通知被拆成六卡，组织方式退步。此实验被拒用于长通知，仍保留首次结果记录。最终长通知/多来源继续使用r6，未将这次长文实验描述为成功加速。

## 关键事实与剩余限制

短样本选定关键事实核对通过：数学报名保留意愿条件、原链接和缺年份截止；评教保留本科生对象、课结束后的相对期限、操作入口、认证选项、密码恢复及匿名规则；英语考试保留考试区间、五个教室编号、四个程序钟点、携带材料、无需耳机及迟到限制。评教菜单导航与可选认证保存在details，零steps符合现有合同。英语考试范围虽然保留在原文说明中，结构化任务时间仍unknown；不能称所有日程已结构化。

历史首次公网`SCHEMA_INVALID`缺少失败正文与细分类别，根因仍未确认；六次结构成功不能证明消除所有偶发失败。历史r6多来源角色样本的一般要求与特殊分支仍局部重叠。
