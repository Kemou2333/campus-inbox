# 应用市场准备清单

核对日期：2026年10月14日。当前交付为网页和 Android APK；商店资格、材料及 AI 分类仍需各平台确认。本轮没有注册开发者、提交身份材料、接受平台协议或申请新的付费服务。

## 提交前要准备的材料

1. 确定一致的主办主体、应用名称、联系人和客服入口，完成对应开发者实名认证。
2. 办理 APP 备案，确认后台网络资源和主办主体相符。网站 ICP 与 APP 备案不要混淆；按要求在应用显著位置展示编号。[工信部官方解读](https://www.miit.gov.cn/jgsj/xgj/hlwgl/art/2023/art_564bf0759d7e41d5b4aa8ce4996b9e84.html)
3. 准备平台认可的软件版权证明。不同平台接受的证书形式、授权材料不同，申请前先核对。[小米资质问题](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2251)、[OPPO上传流程](https://open.oppomobile.com/bbs/forum.php?mod=viewthread&tid=6304)
4. 用稳定的 HTTPS 地址提供完整隐私政策与用户协议。写清账号、通知原文、AI 服务、云同步、本机附件、可选维护查阅及保留规则，政策与真实行为一致；本版仍需补齐正式商店材料与账号注销流程后再申请。
5. 准备图标、实际截图、短介绍、权限用途说明、版本说明和审核专用测试账号。审核账号不使用自己的真实通知或生产管理员权限。
6. 保持现有包名和签名以支持覆盖安装，保存签名私钥的私密备份。完成真实 Android 设备的安装升级、系统通知、节电、重启及权限检查。
7. 向平台描述“用户提供校园通知、AI提取、原文出处与人工修正”的真实功能，核实是否归入生成式 AI/深度合成类别，以及内容标识、算法备案、安全评估或模型合作证明要求。不能仅凭使用已备案模型就推断自身全部义务已满足。[华为资质文档](https://developer.huawei.com/consumer/cn/doc/distribution/app/80301)、[华为相关法规说明](https://developer.huawei.com/consumer/cn/doc/distribution/app/50108)

Android APK 分发与原生 HarmonyOS 应用是不同交付。当前 APK 不能称为原生 HarmonyOS NEXT 版本；若目标是原生鸿蒙商店类别，需要另做适配和审核。

## 比赛展示可继续做的功能

- **通知变更对照**：同一通知更新时突出截止、材料和对象的变化，用户确认后更新待办，保留旧版出处。
- **个人行动清单**：选择年级、身份与已完成状态，按原文明示条件筛选“我现在需要做什么”，资格不足明确显示，不让 AI 猜个人身份。
- **一键演示流程**：用已脱敏通知演示粘贴、整理、点出处、纠错、关闭恢复、系统提醒，全程保护真实账号；优先用固定样本避免现场耗时波动。

这些是后续建议，本轮不扩展到自动抓群消息、公开社交发布或后台读取同学私人内容。
