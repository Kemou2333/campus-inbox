# AI 处理边界

通知和问题经服务端发给 DeepSeek；输入敏感信息前请先自行遮去。完整数据流见 [隐私说明](PRIVACY.md)，用量和有效期统一查 [限额标准](LIMITS.md)。

## 输入与权限

- 真实整理和提问需要有效账号。服务在调用模型前检查正文长度、来源数量、请求字段和账号权限。
- 模型只收到系统规则、通知正文及本次问题，不接收登录令牌、SMTP凭据、服务器配置或附件文件。
- 通知中的“忽略规则”、伪造角色、索取密钥或执行代码要求均作为正文处理。服务不给模型执行工具，也不自动抓取正文里的网址。
- 明显超出通知用途的有害生成请求会被本地规则或同次模型请求拒绝。规则不能覆盖所有变体。

## 输出与原文

- 使用 JSON 输出模式，服务继续验证完整响应、字段结构、来源映射、日期及链接；截断、未知字段和不完整内容不能作为有效结果入库。
- 一批输入只发一次模型请求，失败不自动付费重试。使用 low 思考；具体超时与输出上限见限额标准。
- 链接按对应原文校验，拒绝带用户信息的地址及无来源新增链接。链接出现在原文中不等于该网站可信。
- 网页将结果作为文本或受限 Markdown 显示，不执行模型提供的脚本或HTML。
- 结构校验不能证明事实完全正确。原通知始终保留，重要日期、对象与办理要求仍须核对。

## 费用与任务恢复

账号、IP和全站次数分别计数，两类AI请求共用日费用预算，并限制并发。费用先预留、后按合法返回用量结算；缺失用量保留预留，已派发失败也不自动退回次数。状态无法安全读取或保存时，停止新增付费调用。

相同账号、同提交编号及同规范化正文只创建一个任务。已确认的云任务不会因关页或断网重新派发；合法结果保存失败时，只重存已有结果，不再调用模型。异常重启会明确标记未结束任务，不自动收费重试。

完全相同的原文及来源顺序可复用短时结果缓存；鉴权和短时频率限制仍然执行。缓存只按提交内容匹配，不向其他账号公开用户通知列表、笔记或进度。

账号和配额记录保存在同一业务后台；更换入口、设备或发布版本不清空原用量。运维迁移应保留原账本，不能用删除状态文件的方式回滚。

## 维护

公开示例与真实首响应明确区分。自动化测试使用固定响应，不能据此声称模型准确率；少量真实样本也不代表普遍质量。历史实验及逐版日志由维护者本机归档，仓库保留执行代码与必要的脱敏测试样本。
