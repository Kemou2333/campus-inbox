# AI 整理的边界与费用保护

这轮加固针对校园通知整理。测试使用本地固定模型响应，没有真实调用 AI，也没有替部署后的模型表现或法律合规作保证。

## 输入与模型权限

- 生产入口要求有效登录账号。每批只有 `notice` 或 `sources:[{text}]`，合计最多 4,000 字、最多 20 个来源；多余字段、附件、客户端编号和本地状态会在付费调用前被拒绝。
- 每批只发一次现有 DeepSeek 请求，没有额外付费审核。模型只收到固定系统政策与通知文字；服务签名密钥、账号令牌、SMTP 凭据和服务器配置不会加入消息。模型 API Key 仅用于发给固定服务端点的认证头。
- 原文中的伪造角色、改规则、索取密钥、执行代码、访问链接等要求只是数据，不具备指令权限。服务不给模型工具，不抓取用户提供的网址，不上传或读取附件。
- 窄范围本地规则拦截明显的直接色情创作、盗号、制毒等生成请求。它不是完整的内容审核器；校园安全提醒、反诈案例、性教育、预防性侵及举报流程仍可整理。模糊情况由同一次模型请求中的系统政策处理。
- 不属于通知整理，或主要目的是生成露骨色情、实施诈骗/盗号/入侵/制毒/爆炸/洗钱等有害操作时，系统要求整批返回唯一拒答对象：`{"schemaVersion":4,"refusal":"UNSUPPORTED_REQUEST"}`。服务转为安全的 422 错误，内部失败类别为 `CONTENT_BOUNDARY`；不返回模型的拒答原文、理由或示例。正常结果仍使用原有第 4 版通知与结构化时间字段。

## 输出与来源

服务先确认上游确实完整结束，再验证 JSON 和原有严格 schema。多余字段、工具调用、错误数量、截断与不完整结果都不能进入缓存。拒答对象带其他字段或未知枚举同样失败。

明确来源的卡片数量有硬校验，并按输出数组位置绑定原文；语义顺序仍依赖模型合同。ISO 日期和结构化时间分量按对应来源校验，普通时间文字仍属于模型提取结果。HTTP(S) 链接按来源提取核对，包含 Unicode 域名与路径；ASCII 网址后紧邻中文说明时允许保留原网址前缀。新生成或从其他来源借用的链接会整批拒绝。网址边界存在文本歧义，这项校验不是网站可信认证；服务不会替用户打开或验证网站。其他语义事实与事项归属仍依赖模型政策，不能靠结构校验证明全部准确。

前端的文本/Markdown 安全呈现与服务器的 schema 校验共同负责输出使用边界。模型输出没有代码执行、工具执行或服务器网络访问权限。提示词政策与简单筛查也不能保证识别所有变体，因此不能把它们描述为完全防注入或法律全面合规。

## 正常使用与费用上限

| 保护 | 生产行为 |
| --- | --- |
| 账号短时频率 | 稳定账号每 3 分钟最多 5 次，包括免费缓存；换设备、令牌或网络不会刷新 |
| 同一网络短时频率 | 已登录流量每 3 分钟最多 20 次，降低校园共用网络对单个同学的影响 |
| 图片验证码 | 自己账号第 3 次及以后的未缓存请求触发，其他同学的请求不会增加自己的触发频率 |
| 单次验证码 | 绑定账号、IP、原文、网页来源，2 分钟有效，最多 5 次猜测，成功后立即消耗 |
| 付费次数 | 全站每天 30 次、账号每天 10 次；本轮生产配置将共用网络日限设为 30，避免同学共用网络时过早受限 |
| 并发 | 全服务同一时间只允许 1 次未缓存模型请求 |
| 失败与取消 | 已预留或派发的请求仍计入次数上限；失败不自动重试、不缓存，已收到的合法用量保留 |
| 重复通知 | 完全相同的文本和来源顺序可复用 15 分钟缓存，最多 50 项；鉴权与短时限频仍适用 |

全站、网络、账号付费次数和账号短时频率会以哈希身份写入私密状态文件，先持久化预留再派发请求。状态损坏或无法保存时停止新增付费调用。未明确配置的全站日限为 30，非法日限配置不能变成无限预算。日期按固定的上海时区重置，不根据 IP 推断用户所在地。

缓存仅依赖本次原文及明确来源结构，没有个人身份条件，因此可跨账号复用；不将一个账号的通知列表或私人上下文发送给另一个账号。

取消信号由 Node HTTP 适配层从实际连接关闭映射到 `Request.signal` 并传到上游。若上游迟到或忽略取消，完成结果也不会进入缓存；取消无法保证收回已经发生的模型计费。这些限制保护 AI 调用预算，不代替公网入口的流量防护。

若需要回退到旧版服务，必须同时处理配额状态格式：新版共用网络最多保留 20 个短时记录，旧版最多接受 5 个。不能靠删除 usage.json 清空当日预算来回滚；应先备份，再保留付费次数和用量，并为旧版保留最近 5 个网络记录。正常向前部署无需清空状态。

## 验证与依据

本轮一次运行 67 项相关测试全部通过，包括实际信号转发、取消后不缓存、失败用量保留、严格拒答、来源链接、校园共用网络公平性，以及现有来源输入、验证码、配额和并发测试。全部通过本地模拟完成，没有付费调用。

设计参考 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)、[OWASP 提示词注入防护说明](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html)与 [OWASP LLM01](https://genai.owasp.org/llmrisk/llm01-prompt-injection/)。提示词只是其中一层，可信输入结构、无工具权限、输出验证及硬预算共同限定实际影响。
