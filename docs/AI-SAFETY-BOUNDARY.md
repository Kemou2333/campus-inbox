# AI 整理的边界与费用保护

这轮加固针对校园通知整理。免费测试使用固定模型响应；2.7另用办事簿中真实短通知小批测试low返回速度，记录自然首次响应，不人工改写模型结果。结构检查不能替模型事实正确性或法律合规作保证。2.7当前待发布及公网验收。

## 输入与模型权限

- 生产入口要求有效登录账号。旧 `/analyze` 每批只接收 `notice` 或 `sources:[{text}]`；新 `/analysis-jobs` 另接收经验证的稳定UUID `requestId`，用于同账号幂等提交，不发送给模型。正文合计最多 4,000 字、20个来源；多余字段、附件和本地通知状态在付费调用前拒绝。
- 每批只发一次现有 DeepSeek 请求，没有额外付费审核。模型只收到固定系统政策与通知文字；服务签名密钥、账号令牌、SMTP 凭据和服务器配置不会加入消息。模型 API Key 仅用于发给固定服务端点的认证头。
- 原文中的伪造角色、改规则、索取密钥、执行代码、访问链接等要求只是数据，不具备指令权限。服务不给模型工具，不抓取用户提供的网址，不上传或读取附件。
- 窄范围本地规则拦截明显的直接色情创作、盗号、制毒等生成请求。它不是完整的内容审核器；校园安全提醒、反诈案例、性教育、预防性侵及举报流程仍可整理。模糊情况由同一次模型请求中的系统政策处理。
- 不属于通知整理，或主要目的是生成露骨色情、实施诈骗/盗号/入侵/制毒/爆炸/洗钱等有害操作时，系统要求整批返回唯一拒答对象：`{"schemaVersion":4,"refusal":"UNSUPPORTED_REQUEST"}`。服务转为安全的 422 错误，内部失败类别为 `CONTENT_BOUNDARY`；不返回模型的拒答原文、理由或示例。正常结果仍使用原有第 4 版通知与结构化时间字段。

## 输出与来源

服务先确认上游确实完整结束，再验证 JSON 和原有严格 schema。多余字段、工具调用、错误数量、截断与不完整结果都不能进入缓存。拒答对象带其他字段或未知枚举同样失败。

每张模型卡片带输入框 sourceId；服务验证范围、顺序及所有来源完整覆盖，剥离该字段后返回必要的 sourceIndexes。一个输入框可拆多条独立主题，具体原文与附件依据映射绑定；同一事项的角色任务与步骤仍放一张卡。语义分卡仍依赖模型合同。ISO 日期和结构化时间分量按对应来源校验，普通时间文字仍属于模型提取结果。HTTP(S) 链接按来源提取核对，包含 Unicode 域名与路径；ASCII 网址后紧邻中文说明时允许保留原网址前缀。新生成或从其他来源借用的链接会整批拒绝。网址边界存在文本歧义，这项校验不是网站可信认证；服务不会替用户打开或验证网站。其他语义事实与事项归属仍依赖模型政策，不能靠结构校验证明全部准确。

前端的文本/Markdown 安全呈现与服务器的 schema 校验共同负责输出使用边界。模型输出没有代码执行、工具执行或服务器网络访问权限。提示词政策与简单筛查也不能保证识别所有变体，因此不能把它们描述为完全防注入或法律全面合规。

## 正常使用与费用上限

| 保护 | 生产行为 |
| --- | --- |
| 账号短时频率 | 稳定账号每 3 分钟最多 5 次，包括免费缓存；换设备、令牌或网络不会刷新 |
| 同一网络短时频率 | 已登录流量每 3 分钟最多 20 次，降低校园共用网络对单个同学的影响 |
| 图片验证码 | 自己账号第 3 次及以后的未缓存请求触发，其他同学的请求不会增加自己的触发频率 |
| 单次验证码 | 绑定账号、IP、原文、网页来源，2 分钟有效，最多 5 次猜测，成功后立即消耗 |
| 付费次数 | 全站每天 30 次、账号每天 10 次；本轮生产配置将共用网络日限设为 30，避免同学共用网络时过早受限 |
| 费用 | 默认全站每天 3 元保守估算额度；派发前预留完整输入与输出上限，收到实际用量后结算。未知用量保留预留值，重启不会清空 |
| 并发 | 全服务同一时间只允许 1 次未缓存模型请求 |
| 失败与离开 | 已预留或派发的请求仍计入次数上限；模型失败不自动重试、不缓存，已收到的合法用量保留。云任务持久确认后客户端离开不取消模型；只免费重存已生成结果不会再次调用模型 |
| 幂等任务 | 同账号、同稳定UUID、同规范化正文只创建同一任务；并发提交或未知确认的显式确认不会额外派发模型 |
| 重复通知 | 完全相同的文本和来源顺序可复用 15 分钟缓存，最多 50 项；鉴权与短时限频仍适用 |

全站、网络、账号付费次数和账号短时频率会以哈希身份写入私密状态文件，先持久化预留再派发请求。状态损坏或无法保存时停止新增付费调用。未明确配置的全站日限为 30，非法日限配置不能变成无限预算。日期按固定的上海时区重置，不根据 IP 推断用户所在地。

缓存仅依赖本次原文及明确来源结构，没有个人身份条件，因此可跨账号复用；不将一个账号的通知列表或私人上下文发送给另一个账号。

2.7的云任务先持久保存来源正文、提交编号及状态，再派发模型；来源与结果属于该账号的私有同步数据库，不写入匿名化用量日志。客户端停止等待、断网、关闭页面或应用都不撤销已经确认的任务，也不能承诺免除已经发生的计费。成功结果以稳定记录ID原子写入账号空间；客户端正常同步，不用结果快照复活用户删除的通知。用户笔记、进度和本机附件不发送给模型。

合法结果先持久保存；云写入暂时失败时标记可免费保存的结果，`/analysis-jobs/<id>/save`只保存该快照，不再调用模型或申请新AI预算。服务正常停止给在途请求留出处理时间；异常重启把未终态任务明确标记失败，保留来源，不自动重新收费派发。没有合法结果时，仅由用户决定是否恢复原文重新整理。

旧 `/analyze` 为兼容客户端保留连接取消信号转发；上游迟到或忽略取消时不进入缓存，取消也无法保证收回模型计费。流量防护、硬预算与私有账号空间仍须独立保持。

若需要回退到旧版服务，必须同时处理配额状态格式：新版共用网络最多保留 20 个短时记录，旧版最多接受 5 个。不能靠删除 usage.json 清空当日预算来回滚；应先备份，再保留付费次数和用量，并为旧版保留最近 5 个网络记录。正常向前部署无需清空状态。

## 验证与依据

早期加固的67项相关测试通过，包括信号转发、取消后不缓存、失败用量保留、严格拒答、来源链接、共用网络公平性及验证码、配额与并发。2.7本地免费检查前端213项、后台231项通过，另有六次首次真实low实验；短通知首次观察4.470–17.183秒。r8评教比r7该次更快，但r8长文更慢并被弃用于长输入；不能将提示精简一概称为加速。各项实际范围与待发布边界见 [2.7 验收记录](VALIDATION-2.7.md)，历史观察见 [2.5 验收记录](VALIDATION-2.5.md)。

设计参考 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)、[OWASP 提示词注入防护说明](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html)与 [OWASP LLM01](https://genai.owasp.org/llmrisk/llm01-prompt-injection/)。提示词只是其中一层，可信输入结构、无工具权限、输出验证及硬预算共同限定实际影响。

## 模型模式与保守费用估算

2.7默认 `AI_THINKING_MODE=low`，启用低强度思考，一批只调用一次，不自动付费重试。一个来源且规范化正文不超过600字使用r8精简提示；其他输入使用r6完整提示。r8要求直接摘录、以约100个思考token为短核对目标并立即输出；这只是提示词要求，不能硬控思考token或固定秒数。模式仍为low，没有关闭思考。短通知也可能因复杂条件耗时较长，不能将一次快响应承诺给所有输入。

维护者显式设 `none` 可关闭思考。非思考最大输出12,288 token，low总生成预算32,768 token（包含思考）；非思考上游45秒超时，low180秒。32,768是完整生成上限，不是每次实际消耗，也不能通过简单压低上限代替短核对，否则可能把完整JSON截断。旧 `/analyze` 代理等待195秒，云任务提交与查询返回短确认；发布时另核对运行中配置与systemd停止等待，不凭源码宣称生效。

`AI_DAILY_BUDGET_RMB=3`。按 DeepSeek Flash 峰值美元单价、输入未命中缓存和保守 8 元/美元计：输入每 token 2.4 微元、输出每 token 9.6 微元。思考包含在输出 token 中，不能再计一次。请求派发前按完整 UTF-8 输入加格式余量及最大输出预留；成功或失败返回合法用量均结算，缺失/非法用量及未知取消保留预留。旧状态按既有 token 总数迁移，不重置次数或日期。估算不是账单，价格变动时需更新费率。

同提示词、同 2,653 字原文的两次单独实测：非思考 6.75 秒/估 0.026621 元，low 42.45 秒/估 0.107888 元。low 在多角色、多条件与步骤组织上更稳，不能据单一样本认定所有场景都更好；非思考更适合快速交互，复杂通知仍可能遗漏或误分对象。所有示例保留生成来源与模式，不手工修改摘要来掩盖问题。

价格与模式依据：[DeepSeek 价格](https://api-docs.deepseek.com/quick_start/pricing/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。
