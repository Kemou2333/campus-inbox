# 整理质量修订 r30

以 r29 冻结版本做同题首响应比较。本轮先检验通用候选，再检验收窄候选；每个候选输入只取一次自然响应，保留弃用结果，没有收费格式重试。最终只采用多赛项及合集的局部约束，高数维持 r29。

- 多赛项的共有报名与入群放在一项，独有的初选提交物分别列项。赛项/身份作短条件，组队人数、跨校和作品数限制放说明，未来决赛单独说明。
- 完全相同的外卡取证窗口集中保留，三个通道的证书门槛、排序名额、审核、报销条件分别保留。
- 合集逐来源核对年龄建议、身份例外、角色和后续阶段；“建议年满18周岁后”保留年龄与语气，不强化成硬性资格。

比赛样本可见文本由1673字降至1474字；这统计所有可显示字段，排除原文、元数据、空白和Markdown标记，不等同首屏文字量。该同题耗时约65.7秒与46.6秒；合集约59.5秒与66.3秒，补回事实后更长。单次差异不代表普遍提速。

本轮共17次真实请求，均通过当前生产校验；这不是语义准确率。仍为 deepseek-flash、low 思考、32768输出上限，日预算和频控未改。按返回用量和当时[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)估算合计约0.63元，不是逐条账单；高峰单价口径约1.26元，未超过本轮2元上限。

弃用的通用候选曾让复杂比赛达到约102秒；另一收窄候选遗漏国际中文组的创作依据，均未整体采用。高数新候选把导航动作变成过多勾选，故维持 r29，不把字数减少当作进步。开发者面板5条原样结果均核对为当前实际输入所用提示词，普通分支直接复用本轮r29首响应，没有再付费调用。
