# 公开示例的脱敏

公开示例来自真实通知与真实模型首次响应。测试时使用原文；对外展示前另做人工脱敏，两份不能混为一份。`public/examples-provenance.json` 保留原始测试与首次响应的 SHA256，并另记公开内容的 SHA256，明确标记 `manualPrivacyEdits: true`、`manualWordEdits: true`、`manualContentCorrections: false`。隐私编辑不是对模型结果的事实修补。

每次载入新的示例、更新示例或发布之前，都要人工通读完整原文与所有结构化字段，包括说明、步骤、材料、注意、提醒、附件引用、链接以及来源记录。人物使用明确标注的化名；真实手机号、群号、学号、邮箱、私人表单链接和其他可识别个人的信息隐藏或替换，专业班级等可关联特定群体的信息也按需改为示例称呼。保留任务含义、条件、角色区分、数字、日期与先后顺序；不能为脱敏而修改模型对事实的整理。

目前公开示例所有具体链接均替换为不可点击的「链接已脱敏」。原通知存在网址矛盾时，同一网址使用一致的A/B占位，不同网址使用不同占位，以免脱敏抹掉原始差异。隐藏的联系方式不能用于实际报名或办理，读者应查自己的原通知。示例原文有「脱敏示例」说明，载入入口也说明脱敏；用户自己粘贴的通知保留原文，不自动改写。

原始通知、首次响应、人工核查映射与复核记录只放本地私有结果目录，不放 `public/`、源码、发布包或公开记录。公开旧版注册表只包含内置示例 ID 与完整记录的指纹，不含通知正文。载入新版仅替换完整指纹匹配且未修改的旧示例，用户的笔记、完成状态、个人时间、附件和编辑均保留。

人工复核之后运行 `node scripts/verify-example-privacy.mjs`。它核对公开内容与人工复核的哈希一致，检查手机号、邮箱、证件号、群号、学号及未隐藏链接，并确认旧版注册表只有 ID 和指纹。错误只报告字段路径与类别，不输出敏感原值。自动检查不能可靠识别人名或上下文组合身份，因此不能替代人工通读；示例内容任何变化后都要重新复核并更新公开哈希。

过去已公开的版本仍可能存在于历史提交、旧 APK 或缓存中。本次处理更新当前公开文件和新安装包，未重写仓库历史，也未删除既有用户记录。

2.11新增六条示例共选用六个真实首次响应，全目录合计19条。数学首次响应曾被旧版每步五条细节的限制拒绝；公开版本使用同一份首次响应经最多二十条的有界合同免费复验，未再次付费、未修补语义。其结构化部分遗漏可提交素材中的音频类型，保留这项局限，不把含完整原文当作结构化输出已完整的证据。其余泛化摘要、重复内容等限制也记在来源记录中。
