# 公开示例的脱敏

当前公开目录是**24条人工润色、隐私审查后的展示样本**，基于历史真实通知与首次模型响应，不是未经改写的模型成绩单。`public/examples-provenance.json` 保留历史原始来源、首次响应与失败限制；另签公开内容哈希，并以 `sourceKind: human-curated-public-example`、`manualPresentationEdits: true` 明示展示稿。开发者“真实测试结果”另存 `public/model-tests.json`，只审查隐私，不润色，不因展示稿更新而改写。

2026-10-23逐条复核全部24条结构化展示、8条填入原文、1条教程副本和24条固定问答。八份输入共由4005字缩至1804字，去掉重复宣告与宣传性语句；高数重复交代集中一次，外卡通道报销条件合并说明，各赛项不同门槛保留。只有相同历史原文的10条目录记录更新了公开原文，其余原文保留；历史原始通知、首次响应及其SHA256不变，未调用模型。公开输入的精简在每条来源记录单独标识，不能把它称为原始聊天逐字稿。

每次载入新的示例、更新示例或发布之前，都要人工通读完整原文与所有结构化字段，包括说明、步骤、材料、注意、提醒、附件引用、链接以及来源记录。只用审查清单里的常见化名；真实手机号、群号、学号、邮箱、私人表单链接和其他可识别个人的信息隐藏或替换，专业班级等间接身份按需改为示例称呼。人工精简保留原意、条件、角色、数字、日期精度与先后顺序，不猜缺失信息，不改变模型原始测试记录。

具体网址统一使用 `example.com` 的不同业务路径，号码用含X占位，人名只用李华、李老师、王老师等已批准化名；正文不重复隐私声明。网址矛盾保留不同入口与明确提示，不能为美化而消除。示例联系方式不可用于实际报名，用户自己的通知保留原文，不自动改写。

上版已填入、尚未整理的8条内置草稿保留精确旧原文别名；别名逐条重审并签哈希，发布门禁一起扫描。只有明确示例标记、全文精确匹配且无附件才可免费返回新版展示副本；个人文本或任何编辑不会被当作内置示例。旧目录仅完整未编辑记录指纹匹配时更新，个人笔记、完成状态、收藏、优先级和附件都受保护。

原始通知、首次响应、人工核查映射与复核记录只放本地私有结果目录，不放 `public/`、源码、发布包或公开记录。公开旧版注册表只包含内置示例 ID 与完整记录的指纹，不含通知正文。载入新版仅替换完整指纹匹配且未修改的旧示例，用户的笔记、完成状态、个人时间、附件和编辑均保留。

人工复核之后运行 `node scripts/verify-example-privacy.mjs`。它核对公开内容与人工复核的哈希一致，检查手机号、邮箱、证件号、群号、学号及未隐藏链接，并确认旧版注册表只有 ID 和指纹。错误只报告字段路径与类别，不输出敏感原值。自动检查不能可靠识别人名或上下文组合身份，因此不能替代人工通读；示例内容任何变化后都要重新复核并更新公开哈希。

身份核查单独记录为 `privacyReview.manualIdentityReview: true`、`identityCategoriesReviewed` 及每条来源记录的 `manualIdentityReview: true`。至少人工检查人物真名和学生标识；总声明与每条记录缺一不可，不能靠重新计算哈希绕过姓名与学号审查。该签记只表示维护者完成隐私复核，不证明 AI 整理事实准确。

发布门禁检查学号等数字、字母数字组合，包括强调标记里的号码；明确“姓名：具体名字”须在已批准化名表里。“请填写姓名、学号”只是办事要求，保留即可。门禁核对公开原文与完整记录哈希、人工身份签记和展示稿来源，任何一项缺失都拦截。自动检查不能替代逐条阅读，公开示例不用看起来可联络的随机号码。

过去已公开的版本仍可能存在于历史提交、旧 APK 或缓存中。本次处理更新当前公开文件和新安装包，未重写仓库历史，也未删除既有用户记录。

2026-10-14进行了现状只读审查：检查当前公开 main 的全部文件、在线入口及资源、2.12 安装包里的网页资源和当前22条示例的所有文字字段。当前例未发现此前已替换的真实人物、学生标识、群号或私密链接，未命中既有配置密钥；当前网页和安装包的示例内容与源码一致。测试与发信说明中的示例邮箱、公开官方网址和角色称呼另行核查，不直接当成个人信息。

历史审查确认早期通知仍有身份信息和群号：早于2.11的13个既有安装包全部实际命中此前替换掉的真实人物称呼及群号，旧提交中的示例正文也存在同类暴露。具体提交、文件路径、版本及资产编号只列在私密处置清单，不再复制原值或公开提供定位链接。当前分支脱敏不能消除旧提交或旧 APK；如要彻底清理这些可访问入口，需针对 Git 历史与旧发行资产另行确认后处理，不能擅自删除、强推或改权限。下载过的安装包、第三方副本与外部缓存也无法靠重写当前仓库召回。

2026-10-15，用户明确同意清理旧安装包与旧敏感内容后，已按审查清单移除13个旧 APK 下载资产；操作前均核对私密备份哈希与资产编号，删除后逐项确认接口返回404。发行说明页面和版本标签保留，2.11及之后的安全安装包保留，未触及用户账户或云记录。Git 历史清理先做私密完整备份与本地预览，再与正常发布分开执行；完成与否以交付记录为准，不能把旧 APK 下载已下架说成历史提交和外部缓存已清除。

2.11新增六条示例共选用六个真实首次响应，全目录合计19条。数学首次响应曾被旧版每步五条细节的限制拒绝；公开版本使用同一份首次响应经最多二十条的有界合同免费复验，未再次付费、未修补语义。其结构化部分遗漏可提交素材中的音频类型，保留这项局限，不把含完整原文当作结构化输出已完整的证据。其余泛化摘要、重复内容等限制也记在来源记录中。

2.12在原19条逐字段复核且原样保留的基础上追加3条，合计22条。2026-10-14共进行4次有意的首次模型实验，选择r16线代、r17高数、r18助学金；r15线代未选入，因为计分构成被推断成当前待办且遗漏答疑渠道。r16线代原付费响应因超过原3段引用上限拒绝；r17高数原付费响应因步骤组键未被合同支持拒绝。两份原响应都保持原样，仅通过最多8段、有限任务/步骤/时间节点组继承的免费兼容复验；不能将原付费失败改记为成功，也不能把免费回放称为新的模型实测。高数仍遗漏音频选项，原文与这项局限都保留。

公开新例的原文、人物及链接另行人工脱敏，模型原始哈希和公开哈希分开记录。出处先由程序从组关联展开为具体字段，再按隐私替换的真实字符区间重新定位至公开原文，标记`manualSourceRefReanchoring: true`与`deterministicSourceRefExpansion: true`。找不到对应位置或超出有界范围就保留未关联，不能猜段号。出处完整覆盖只表示有可查看的位置，不证明原文全部事实被保留，也不证明模型关联的语义正确。
