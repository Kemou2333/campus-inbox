## 每次修改的记录格式

| 项目 | 填写要求 |
| --- | --- |
| 指标 | 稳定字段名与中文名称 |
| 旧值 → 新值 | 写数值与单位，不能只写“放宽” |
| 范围 | 账号、IP、全站或设备 |
| 窗口 | 滚动时长或明确时区的自然日 |
| 状态 | 待调整／已实现／已发布／已验证 |
| 生效时间 | ISO时间与北京时间说明 |
| 发布版本 | commit或发行版本；无发布则填未发布 |
| 验证与回退 | 后台读取值，保留的旧配置及数据影响 |

待调整标准由维护者确认；不得把讨论中的建议直接写成生产生效值。
