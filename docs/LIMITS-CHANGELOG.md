## 每次修改的记录格式

| 项目 | 填写要求 |
| --- | --- |
| 指标 | 稳定字段名与中文名称 |
| 旧值 → 新值 | 写数值与单位，不能只写“放宽” |
| 范围 | 账号、IP、全站或设备 |
