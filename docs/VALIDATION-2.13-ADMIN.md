# 2.13 后台变更与隔离验收

本文件记录本地候选源码，不能据此宣称已经发布。测试不读取真实账号正文，不调用模型、邮件或生产写接口。

## 功能

- 移除整理提交前“允许作者查看”的勾选；新客户端不发送该字段。旧提交日志仍能恢复原文、附件引用和未知确认状态，不清理用户记录。
- 作者通过受保护的后台查看已保存的原始任务／整理结果，以及各账号当前同步通知。旧许可字段、三十日期限不再限制阅读；原数据库字段及原值留存，旧客户端布尔参数仅兼容接收并忽略。
- 账号列表分别提供“通知”和“整理”：前者包括导入、后续修改、完成／跳过、步骤进度与笔记；后者保留 AI 整理初稿。删除标记不作为通知复活，未上传草稿与本机附件不在服务端。
- 首屏为人类可读统计：今日整理、整理成功、失败、账号、处理中和十四天趋势。按上海时间的提交日期分组，“成功”仅表示整理结果已保存，包含缓存复用，不能解释成用户已经办完事项；历史缺失的逐条指标仍为未知。
- 通知预览通过产品自身静态 iframe 复用真实 React 通知组件。双方严格核对消息 origin 与窗口 source；只发送当前通知数据，不发送会话、不通过 URL 放正文、不存浏览器。产品样式不可用时可展开纯文字简版和 JSON。

## 安全边界

仅配置的既有 kemou 账号可管理，启动时固定该账号 UUID。普通账号即使指定他人编号也不能访问；默认无白名单则关闭。保留只读 API、分页与每分钟六十次后台读取限制；不新增删除、改权、模型重跑接口。邮箱、密码材料、会话密钥和验证码答案不进入后台响应。

登录验证码、刷新冷却、账号／网络限流保持。关于页以普通说明文字披露服务器维护范围，不增加新的许可控件或批准弹窗。
