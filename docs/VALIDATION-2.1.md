# 2.1 阅读与适配验收

网页恢复左侧新增、右侧查看。手机采用单栏，正文、条件标签及步骤说明不再与笔记按钮挤在窄列；统一字号和可辨识按钮，改为中性深色背景。手机横屏、平板横屏和方屏按可用宽度布局，键盘缩短高度时保留输入面板。

## 实际 DeepSeek 测试

使用生产网页的普通批量输入、同一账号、同一生产接口。模型为 `deepseek-flash`，关闭思考；每批只调用一次，不自动重试。已有通知、笔记和附件均不进入请求。

最终两批共 8 条原通知通过以下检查，返回的文字直接保存，不人工润色。示例中的 8 条已更新为这两次结果；另保留 5 条历史模型示例。结果摘要与哈希见 [示例来源记录](../public/examples-provenance.json)。

| 通知 | 已检查的行为 |
| --- | --- |
| 普通请假 | 家长是独立角色；学生有提交截图、填办事簿、智慧学工请假 3 个步骤；“发给我”保留为通知发布者。 |
| 学生评教 | 保留服务号、菜单、认证与忘记密码方式；课程结束前不虚构具体日期。 |
| 助学贷款 | 归为信息，入账与退款进度不变成学生待办；十月中旬不补具体日。 |
| 国庆返校 | 更正年份、按期返校、无法按期返校才请假的条件分别显示；不借用其他通知的请假流程。 |
| 人工智能通识课 | 只针对未选上的学生，保留避开 001 教学班要求。 |
| 新生学籍 | 当前注册对象排除另行通知的港澳台新生；2026 级不能直接补成截止年份。 |
| 军训纪律 | 归为提醒，不造勾选任务；保留因病就医和医院证明的例外。 |
| SRTP | 保留自愿申报受众、平台和两种途径；完整日期的 24:00 转成次日零点。 |

测试期间还发现并修复两类问题：无法拆分的“课程结束前”被模型标为数值全部为空的 partial，导致整批被拒收；模型把“发给我”推断为“发给老师”。前者仅兼容为空的时间精度标签并重新核对原文时间，后者通过明确逐项接收人的提示词复测。保留失败记录，未用手写通知结果替代模型返回。

本轮累计 6 次真实模型调用，包含 2 次格式排错和中间复测；最终通过的两批不是将多次返回拼接成一个结果。小样本通过不能保证所有通知都正确，原文仍可查看，缺失事实保持未确认。

## 免费验收与边界

- 前端 87 项、后端 112 项自动检查通过，涵盖迁移、时间、批量协议、账号、同步冲突、权限、限额与 Markdown 阅读安全。
- 浏览器检查涵盖 320px、390px、手机横屏、平板横屏、方屏及桌面，无横向溢出；深色与 200% 文字仍能阅读。
- 真实面板滚动条可拖动和用键盘操作；键盘降低视口高度不卸载输入，旋转后草稿保留。
- 图片、HTML 或可执行地址不通过 Markdown 加载；系统日历和通知将轻度强调转为普通文字。
- 示例载入不调用模型，不覆盖现有笔记或进度；重复载入按原文或记录 ID 跳过，即使标题改变也不追加同一条原文。
- Android 已按系统栏、刘海和键盘处理一次安全区，并通过签名构建；新版本系统栏、实际键盘、系统日历及通知行为仍需要真机确认，浏览器尺寸检查不能替代真机测试。

iOS 暂不开发。产品采用同一套网页业务与独立原生能力适配，保留后续扩展的位置。

## 易用性补充

新增结果自动切换到所属分类并清空旧搜索；之后记笔记或勾选不会再跳回历史结果。卡片删除保持原来的位置直至收起，撤销可中断收起。空白输入提供粘贴按钮，等待剪贴板权限时用户已输入的内容不被覆盖；移除草稿可恢复原文和附件。HTML、SVG 等附件作为文字预览，不执行内容。

示例快捷链接只调用示例载入流程，不建立独立模式，不跳过账号对真实 AI 的限制。载入完成即可操作已有的模型结果；新页面不显示首次说明弹窗，正常入口仍保留首次说明和帮助按钮。
