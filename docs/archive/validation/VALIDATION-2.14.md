# 2.14 — 收藏、演示引导与阅读颜色

本轮保持逐条滚动、原地逐项展开、手机28px/桌面32px标题和默认系统配色。

- 收藏是本地通知状态，不进入AI合同；可以只看收藏，包含在文字备份与账号同步中。旧记录无需迁移，未提供字段时仍保持原形。旧客户端未携带favorite的编辑保留服务器已有值，显式false可取消；仍按现有版本冲突规则拒绝过期覆盖。
- 每张通知直接显示“不适用”，恢复只改变整条适用状态，保留子任务进度、笔记、收藏及附件。完成按钮56×56px、绿色32px图标。已不适用通知先恢复后才能完成。
- 完成用绿色，提醒用紫色，时间用蓝色，注意用琥珀色，超期/错误用红色；均配图标或文字，不单靠颜色表达。默认浅/深色小字号语义文字对背景对比度测试均不低于4.5:1；未宣称全站无障碍认证。
- 首次进入提供五步引导，可跳过，在问号中重开；模拟粘贴→模拟生成→真实NoticeCard逐项展开→原文→打勾/收藏/不适用。生成的是纯合成、本机内存通知，不读取剪贴板、不调用AI、不保存用户通知、不写日历。关闭后演示丢弃，只有“已看引导”偏好保存在本机。
- 收费模型、prompt与24条脱敏示例均未改动，无新真实模型调用。公开示例四份文件与2.13逐字节一致，沿用绑定内容hash的人工隐私/身份核查签记，自动隐私门禁通过。保留原AI质量局限，不声称此次提升了模型准确率。

验证：299个前端测试（含收藏备份/存储、不适用无损恢复、颜色对比度）及269个后端测试（含跨设备收藏、旧客户端兼容、显式取消、CAS与无效值拒绝）通过；类型检查/生产构建通过。隔离Chrome以320px浅色、1280px深色完成全演示与正式收藏重载/分类/不适用恢复，完成按钮实测56px，无横向溢出和脚本错误；未发生模型、邮件或生产用户写入。现有构建体积提示仍存在。
