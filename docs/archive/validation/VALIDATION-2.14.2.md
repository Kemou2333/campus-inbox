# 2.14.2 — 真实通知演示、操作高亮与简洁文案

按用户反馈，将新手引导缩为粘贴、生成、展开、完成四步，不再教原文核对；原文功能仍保留。标题26/28px、说明19/20px，按动作换行。当前操作控件高亮，周围压暗，说明与导航保持可见；遮罩不接管点击、不拦截键盘。高亮跟随粘贴、模拟整理、通知展开、待办展开和打勾/收藏移动。横屏低高度采用铺满的引导布局。

演示改用已公开、人工脱敏的“本科生评教”真实通知，原记录242字（展示时省去重复脱敏声明，按句分行约214字）。预置的是此前真实模型首次响应，未改其语义，不是本轮新模型结果。原文、摘要、任务说明和步骤与原24条示例中的该记录一致；仅练习时生成独立ID和时间，不写账号或本机通知库，不调用模型。新增隐私门禁校验，演示副本须完整匹配已签记的公开记录，并核对身份审查与原文/记录hash。

列表及设置提示统一为“示例通知已隐藏个人信息”。精简同步、载入示例、提醒和首次整理提示，移除关于页的长后台说明；实际整理的等待、云端保存及重要错误提示仍保留。没有修改用户通知正文或AI结果。默认深色改为灰蓝背景、青绿色主色、更清晰的正文/次要文字与边框；保留跟随系统、Android动态取色、颜色加文字/图标的状态表达。

301个前端测试通过，其中新增真实演示来源一致性与练习ID/进度隔离测试；默认浅/深色六类语义文字对比度测试继续通过。类型检查、生产构建与24条示例/新演示副本隐私门禁通过。隔离浏览器320×740浅色、1280×960深色、640×360横屏验证四步练习、遮罩位置、控件可点击、大字号、无横向溢出、关闭后无个人记录变化；零模型/邮件/生产写入与脚本错误。设置/关于精简文案同时检查。

后端源码未变，不重复部署或迁移；原账号、通知、收藏、进度、笔记、附件及AGPL协议保留。没有新收费模型实验，不能据此宣称当前模型准确率提升。Android系统权限、提醒送达和覆盖安装仍待真机验收。发布/签名/线上资源证据见对应交付清单。
