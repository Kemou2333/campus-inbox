# 2.18 验证记录

本轮只实现用户选中的小功能，沿用现有布局、服务、low与预算。

- 模型输入：仅在发送副本中压缩连续过多空行，单换行、段落、缩进、数字、网址和存储原文不改。整理仍先按原文分段，出处位置不变；问答引用映回原文的精确连续片段，原4000/240/500/1000字限制、原hash和幂等保留。整理原本已忽略空白段，不承诺明显Token或速度改善。
- 搜索：上一处/下一处、当前/总数定位当前可到达的高亮；排除隐藏、编辑、退出动画和重复片段，不把最多3个上下文片段说成原文全部命中次数。主动导航可展开对应通知与任务。
- 未读：本机按账号隔离，升级前已有通知默认已读，示例不制造未读。新收到通知有小圆点，主动展开或搜索导航后消失，刷新保留。不改变通知数据合同或云端进度。
- 完成后收起：只由本机成功的任务/步骤动作触发，停650ms后检查该任务仍已完成，再收起这一项说明，标题与进度保留；手动展开、取消完成、切换页面/搜索/账号等取消待执行收起。尊重减少动画，不改教程。
- 设置回收站：明确删除才保存完整本机快照，30天、50条/2MiB，写失败则不删除原通知；独立scope+entry键避免两个页面互相覆盖副本。恢复用新根ID，不复活旧云删除身份，保留进度/笔记/收藏/修正/附件引用。恢复不擅自重新安排已取消的系统提醒。彻底删除和清空都先确认，附件仍保护其它通知/草稿/任务/账号回收站引用。容量检查并非跨标签全局事务，极端并发可短时稍超自定上限，仍受浏览器空间限制。
- 问题说明：常见技术错误转换为短中文和下一步，设置提供“遇到问题”。复制的状态仅含版本、平台、设备在线、登录是否有效、同步和任务状态，无账号、原文、ID、URL、凭据或原始错误，不主动请求后台。
- Logo打开含封面的简短介绍。首次介绍和设置提供安卓下载，最终蓝奏优先、GitHub直达当前APK备用。下载地址由公开小清单加载，严格校验版本和拥有的主机/路径；安卓不打包动态清单，更新链接无需重新打包。蓝奏上传与新版本地址核验以固定交付清单为准，未上传时不冒称已完成。
