- Guide instructions sit outside the scrolling practice panel. A single dialog backdrop keeps the practice readable; action gates remain paste → organize → expand notice/task → check. The demo stays in memory and makes no model request.

- Android download is offered after actual guide completion and on the web homepage. Native Android does not suggest downloading itself.
- Focused checks: 6 guide/sound, 6 haptic/bridge and 4 first-entry policy cases passed. Final combined TypeScript and production web build passed. Existing CI runs its normal product/native checks separately.
