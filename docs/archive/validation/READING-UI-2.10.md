# 2.10 界面参考与实现取舍

2026-10-11根据用户要求查看Todoist和TickTick的官方任务界面及说明，并对照本地2.7卡片基础修改。参考资料仅帮助确定信息层级，未复制其品牌、图片或完整布局。

- [Todoist任务视图介绍](https://www.todoist.com/zh-CN/inspiration/todoist-new-task-view)：查看实际界面示例，任务内容与紧凑属性分区；子任务、评论等属于任务内的进一步内容。
- [Todoist任务视图说明](https://www.todoist.com/help/todoist/features/use-the-task-view-to-manage-tasks-in-todoist-eDeRDO0C)：点击任务查看和管理详情、子任务、日期等属性。
- [TickTick任务详情操作](https://help.ticktick.com/articles/7055782408586526720)：点击任务进入详情管理；每项任务有自己的操作范围。
- [TickTick功能介绍](https://www.ticktick.com/features)：检查任务清单、子任务和多平台界面展示。

采用的原则是：先扫描任务标题，属性用短提示，需要办理时再打开对应事项。通知仍是本产品的一级滚动卡片，不引入另一套任务业务或新的详情抽屉。

桌面阅读区设置760px上限；对象和时间用自然宽度标签，避免把短文本放进横贯屏幕的框。通知展开后只列各项标题，每项独立展开自己的条件与步骤，复选框只负责完成。长注意和材料另行折叠；原文、附件和提醒功能放入更多菜单。手机保留足够大的标题与自然换行，不用省略号截断简介。

修改只发生在展示层，保留原始模型字段、日期年份、进度、笔记与云端整理流程。官方产品提供的是参考原则，不能据此声称本产品已具有其全部功能或通过用户验收。
