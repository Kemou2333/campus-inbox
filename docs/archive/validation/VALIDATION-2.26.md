# 2.26 产品与数据保护

本轮改动以已发布 0ac687b 为基线，不重做 r30 模型实验；作品介绍与比赛材料仍暂停。

## 产品

- 注册为默认入口，已有账号可直接切换登录。新客户端请求四位邮件验证码，正文验证码独立成段，有效期写“五分钟”；旧客户端仍兼容六位，新旧账号归属不变。
- 开发者设置可分别调整淡入/首次入场和通知展开：1.25、1.5、1.75、2倍，默认1.5；本机保存，尊重减少动画，短内容按高度更快展开。收藏、小旗、展开均44×44。
- 简介阶段不请求示例目录；教程期间或返回页面稳定后静默预热，显式显示时复用，不因下载而导入或更改进度。右上角明确“重看教程”。
- 整条通知笔记支持六种颜色、自动保存和撤销清空，旧笔记/备份/同步兼容。浏览器隐藏创建提醒，原生安卓保留。
- 教程限制全页背景激活、键盘焦点和越界滚动；仅当前真实练习目标、阅读区域和教程导航可操作。首次不能跳过，重看可以关闭。

## 配额与加固

- 整理和提问共享实际付费调用配额：账号滚动五小时5次、72小时20次，同IP滚动五小时5次；全站上海自然日最多50次，原约3元日费用上限继续保留。
- 缓存命中、已提交请求重放、验证码或限额拒绝不额外收费；实际调用失败保留一次计数，账本跨重启/午夜保留。旧每日格式无法重建已丢弃的更早历史，仅保守迁移仍有记录的次数。
- 图形换图间隔30秒；邮箱已有每邮箱3封/小时、6封/24小时、IP20/小时、40/24小时、全站50/24小时，日停发与真实SMTP失败5次当日熔断持久保存。
- 用户暂缓后台每次登录的邮件验证。后台仍沿用密码+图形验证，不把未绑定邮箱的管理员锁在外面；候选实现留在仓库外。

## 审查问题

- #1 同账号换会话/退出重登保留隔离的同步基线；未改旧版本接受远端更新/删除。真实本机改动仍按既有策略保留本机、归档云端；未知基线保留本机副本后接受远端，异步自动决定有版本与内容守卫。
- #2 包装仓库保存不再重读并刷新底层比较基准，过期快照明确拒绝；个人与示例失败回滚。
- #3 同ID完整备份仅补附件，保留当前文字、笔记和进度；复用相同内容，串行导入并在保存失败清理本次无引用文件。
- #4 以真实CommonMark/GFM语义核对最终href，整理和问答拒绝非原文链接及URL用户信息；前端共用安全URL规则，解析器离线随发行包部署。
- #5 生产CSP允许精确的Pages配置来源，API配置与CSP复用同一允许列表。新来源须先发兼容版本，不承诺仅改JSON即可迁移已发布旧APK。
- #6 鸿蒙预览HTTP共用既有精确原生Origin，验证码/登录/提交/读取合同检查；仍没有可安装HAP或真机验收。

## 验证边界

必要领域、认证、配额、附件、同步、链接及部署检查使用临时数据库、合成数据与固定模型响应。隔离Chrome串通首次教程并检查背景点击/Tab/Esc、目录预热、四位输入、笔记颜色、独立速率及正方形按钮。没有发送真实验证码邮件、没有新增付费模型调用；没有安卓或鸿蒙真机验收。CI、线上网页和签名APK的实际发布结果以交付清单为准，构建产物不等同已发布。
