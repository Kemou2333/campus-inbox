# 2.2 验收记录

日期：2026-10-07。网页版与 Android 版本号 2.2.0，Android versionCode 4。

## 本轮改动

- 通知默认收起，首先显示标题、适用对象、时间地点和完成进度；展开按钮有边框和明确状态。提醒显示简短内容，详细步骤、逐项笔记等在展开后使用。
- 新增结果和紧急事项跳转会展开目标；切换页面、屏幕宽度后保留分类、搜索、排序和卡片展开状态。删除后的撤销回到原位置。
- 手机页面两侧留白缩小，详情弹窗距屏幕边缘 8px。原文取消第二层滚动，长附件名可以换行；短窗口中整理按钮随内容滚动，避免遮住输入。
- 本机 PDF 使用延迟加载的本地渲染器预览，支持翻页、缩放与适合宽度。没有调用识图模型或上传文件，PDF 脚本不执行；损坏、密码、超过 200 页和超大页面可保存后用其他软件查看。
- 备份可以仅导出通知文字与办理进度，附件引用缺失时不阻止文字备份。此选项不修改本机原数据。
- 频繁整理采用四位数字 PNG 验证码，在本服务器生成和校验，无第三方账号、验证码套餐或外部脚本。输错可继续填写同一张图片，取消保留草稿。
- 阻止同一时刻的重复提交；达到限额显示等待时间，不自动重试或发起模型调用。

## 交付与实际限制

网站部署、后端部署及签名 APK 由同一提交触发 GitHub Actions，最终提交、运行编号、安装包校验值记录在交付清单中。自托管验证码没有海外网络依赖；不能据本机测试保证所有运营商到 GitHub Pages 的线路表现。

Android 安装包保持原包名和签名，可覆盖安装。浏览器尺寸检查与打包校验不能代替安卓实机测试，系统键盘、安全区、日历和通知权限仍需用户设备复测。

附件预览打开时若窗口跨越手机 / 桌面 960px 布局分界，整理面板会重新挂载并关闭预览；附件和草稿保留，重新点击即可查看。文本、笔记、展开状态及普通页面切换已保持。

当前仍使用邀请码注册，没有启用邮箱、QQ 或微信登录，也没有密码找回功能。将来扩大公开试用时再配置发信或身份平台。
