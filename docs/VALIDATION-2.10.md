# 2.10 卡片宽度与逐项展开验收

本版根据用户反馈，在2.7逐条滚动卡片基础上调整阅读宽度和展开层级。桌面通知区最多760px，适用对象、时间使用自然宽度的短标签，展开入口恢复为小按钮。打开通知先看到待办标题，每项分别展开条件、说明、步骤与笔记。注意、材料和补充简介默认折叠。保留2.9的标题层级、换行、月日显示与同一活动时间去重。

- 前端223项测试、类型检查、生产构建通过。
