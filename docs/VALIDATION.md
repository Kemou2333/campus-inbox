# 当前验证范围

本轮版本为 **2.28.0 / Android versionCode 43**。本页记录代码和检查范围；是否已正式发布请核对 [GitHub Releases](https://github.com/Kemou2333/campus-inbox/releases)。构建产物、浏览器模拟和实际手机安装是不同的证据。

## 本轮改动

- 新载入与重置内置示例时排除教程使用的评教ID，首次仍载入七条；不删除已保存或编辑过的评教，不移除旧原文免费演示兼容。
- “适用条件”改为“适用人群”；页脚、首次介绍和操作区增加轻量隐私说明，明确第三方DeepSeek及敏感信息边界。
- 原生更新检查取消联网前先弹旧缓存，手动检查验证本轮响应；阿里云独立元数据从已批准稳定安装包索引选最高数值版本，GitHub为固定备用。
- 新增本机待办桌面小组件，独立摘要缓存、切账号保护，无周期任务或额外联网；支持点击返回通知。
- README加入真实界面截图与短动图，历史版本验证文档归档，保留旧结果和失败记录。

## 已有证据

- 示例选择、重置与旧原文兼容的45项聚焦检查通过。
- 桌面小组件摘要、账号范围切换及原生桥的23项聚焦检查通过。
- 独立最新版本元数据的两项本机HTTP检查通过，含GET/HEAD、最高数值版本、热读和不计下载额度。
- 隔离Chrome在1280×900和390×844检查首次隐私说明、七条示例、教程ID排除、适用人群与横向溢出；无模型请求。README媒体来自这套真实产品界面，示例为已脱敏人工展示稿。
- Android CI运行纯Java更新边界、WidgetSnapshot边界与签名构建。签名安装包发布时另核对原包名、既有证书、资源和实际资产摘要；不能只凭Actions成功就声称已发布。

## 未验证与兼容边界

本机无JDK/Android SDK，未做QQ/Via或Android真机安装，也未在真实桌面启动器上验收小组件、长按添加、尺寸变化或系统更新安装。视觉设计示意不属于真机截图。

已安装的2.25.1/2.26旧缓存逻辑无法远程修改。用户可直接下载最新同签名APK覆盖安装，无需逐级安装；新版修复之后的检查行为，不宣称旧二进制被远程改好。细节见[更新说明](ANDROID-UPDATES.md)。

本轮未重复收费质量实验，r30/low提示词、历史原始模型结果、AI额度和普通附件本地存储边界保持。阿里云下载独立验证码/额度规则仍见[下载保护](APK-DOWNLOADS.md)。蓝奏和比赛材料继续暂停。

[历次验证归档](archive/validation/README.md)保留当时状态，不把历史通过次数汇总成整体准确率。
