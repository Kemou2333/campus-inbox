# 整理质量修订：r29

这轮重点是让真实整理结果更容易扫读，接近展示示例的清楚程度。没有改写模型原响应来制造效果。

- 适用条件改用短标签，通常8–24字，优先压缩到32字内。复杂资格的与、或、排除关系仍要保留，不能靠截断省字。
- 标题说事项，简介补充标题之外的一条背景或安排特点。招新、考试类增加了短的正反示例，避免“某某报名，某年级可以报名”这类重复。
- 简介、说明选择少量关键短语加粗，突出入口、材料选项和限制；条件、时间和标题仍为纯文字。

真实实验8次，均保留第一次自然响应，低思考、32768输出上限和原生产限额不变。前6次用于旧新对比及不同通知检查，后2次单独检验招新、考试简介。没有收费重试。

最终开发者面板展示高数、外语比赛、篮球、英语考试4张原样结果，对应各输入实际使用的最终提示词哈希。最终4条平均约34秒；同一组复杂通知的新稿平均约50秒，旧稿约43秒，不能据此声称提速。

原8次中有1次篮球响应给步骤多写了空的任务元数据。程序仅兼容步骤里的 `time:null`、`timeText:""`、`location:null`；非空时间、地点和未知字段仍拒绝。原失败诊断和原响应保留，只免费重放验证，没有补写事实或改字。最终展示的4张首响应本身都不需要这项空字段兼容。

公开输入沿用已审查的化名和example.com；新响应又经过自动扫描与人工隐私核对。Markdown包裹的保留域名链接可正确识别，真实域名、恶意主机后缀、查询参数仍拒绝。

仍有局限：高数的重修免做说明偶有重叠；复杂比赛的完整资格和后续阶段说明仍较长。小样本也不能证明所有条件都会变短，或回答已稳定达到人工整理水平。
