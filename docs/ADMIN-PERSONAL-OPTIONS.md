# 后台与比赛后自用：下一步候选

这些是后续建议，不代表本轮已实现，也没有自动提高真实额度或修改注册权限。适合先选两三项。

## 管理员功能

| 候选 | 能解决什么 |
| --- | --- |
| 每人额度档位 | 试用用户低额度，作者高额度；全站仍有总预算保险丝 |
| 问答与整理分开统计 | 看清每天两种功能各用多少次、多少估算费用 |
| 失败与耗时看板 | 区分模型慢、格式失败、网络失败、额度耗尽 |
| 试用反馈箱 | 用户可附一条通知提交“漏了什么”，便于集中修复 |
| 备份状态与恢复演练入口 | 明确最近备份是否成功，恢复先在隔离副本验证 |
| 容量看板 | 只看数据库、备份、剩余磁盘与条数，不展示复杂监控 |
| 邀请码批次 | 为评委、同学分别发放，限定人数和期限 |
| 功能开关 | 高峰期临时只开放浏览/同步，关新增AI调用；需本人确认 |
| 成本阈值提示 | 后台接近预算时显眼提示，不新增短信或付费通知服务 |
| 维护记录 | 记下部署、额度调整、备份/恢复等管理操作，便于排查 |

最推荐先做：每人额度档位、问答/整理分开统计、失败与耗时看板。

## 转为自己使用

- 个人学期模板：常用课程、默认提醒提前量、时间与展示偏好。
- 今日与本周清单：把个人任务按时间汇总，不再逐条翻通知。
- 课程归档：按课程、比赛或日常事务整理，优先用本机规则，避免反复发送整库。
- 每周回顾：已完成、延期、仍未处理的任务；可先本机生成。
- 材料准备清单：身份证明、表格、报告等整理成可勾选清单，来源仍可核对。
- 常用提问：保存“要交什么”“我什么时候做”“去哪里办理”等个人快捷问题。
- 更细的个人提醒：不同课程默认不同提前量，保留手机节电与强停的送达限制。
- 个人资料检索：以后需要跨通知问答时，先在本机找少量相关段落再提问，不把全部历史每次发给模型。

可以以后给自己更高的次数/金额上限，其他账号保持小额；上限只是保险丝，不会自动产生花费。必须同时协调个人次数、问答次数、网络次数、全站次数与全站预算，不能只调一处。当前生产值仍保持：问答每日5次；账号每日总计10次；全站30次/3元（以实际运行配置为准）。本轮没有实现管理员可编辑的每人差异化额度。

比赛结束若想关闭公开注册、只保留自己或邀请用户，可以另行明确确认后调整；不在本轮擅改访问权限。
