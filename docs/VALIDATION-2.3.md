# 2.3 界面验收

日期：2026-10-07。网页与 Android 版本 2.3.0，Android versionCode 5。保留原包名和签名。

## 按使用反馈调整

- 去除标题旁的重复统计，计数只在待办、提醒、已完成分类出现。宽屏直接从分类和搜索开始，手机保留页面标题与新增入口。
- 整批总字数只出现一次，在最后一个输入框下方；整理按钮独立占满一行，高 56px。多个输入仍共用原来的 4000 字上限。
- 笔记、粘贴、附件和新增使用 48px 图标按钮；有可访问名称和操作提示，不再重复显示图标旁的文字。笔记保存后图标颜色变化，笔记内容仍可直接点击编辑。
- 通知标题手机 24px、宽屏 28px，加粗并允许换行；添加日期从卡片移除，不影响最近添加排序。
- 数据说明移到设置，宽屏通知区域增加高度。卡片使用中性边框，已截止仅由状态与时间强调；首页截止摘要只显示今天和未来三天。
- 深色模式调整中性蓝灰底色、明亮正文和柔和强调色，Android 继续支持系统动态主题。裸网址缩短为域名显示，完整链接保留在地址和悬停提示中，Markdown 有名称的链接保持原名称。
