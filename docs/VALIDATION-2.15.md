# 2.15 验证范围

本版增加本机教学周日期换算、可选个人条件筛选、通知分享图、示例隐藏与分组；README改为产品说明。模型提示词、low强度、后台运行文件和预算未改，无新增真实模型调用或邮件。

## 数据边界

- 年级、专业、固定身份选项和第一周周一保存为本机设置，不加入模型请求、通知备份或云通知。专业24字、字符白名单；年级和身份校验。长度限制不作为提示词注入的唯一防线，这些字段完全不进入模型。
- 筛选只隐藏明确不符的通知，未知条件继续显示。专业简称、年级范围、排除条件、优先条件等保守处理，用户可返回全部。
- 教学周换算依赖用户确认的第一周周一。只换算明确周次与星期；日期冲突、范围、循环和多时刻不补。全天不造具体时刻，24:00跨到次日。派生日期仅用于显示与提醒预填，原文、模型初稿、人工修正与存储通知不回写；手动日期优先。提醒仍需确认。
- 公开示例由当前/历史审查目录38个精确ID识别，不根据通用ID前缀判断。隐藏偏好不删除或更新通知；有真实记录时真实始终在前、示例单独分隔，分类计数不混入示例。
- 分享图使用当前显示内容，导出前保留已应用的人工修正与教学周投影，避免再应用修正丢失日期标注。个人分享不自动脱敏；原文、笔记、附件和账号字段不加入图片。公开24例继续使用既有脱敏内容，原文、结果和provenance字节不变。

## 验证

334项前端单元测试、类型检查、生产构建及示例隐私门禁通过。新增测试覆盖完整分页、中文与长链接换行、上海时间水印、原始记录不变、精确示例身份与偏好、个人条件和周次日期边界。

隔离浏览器验证320浅色与1280深色：真实优先、示例隐藏并刷新恢复、分类计数、保存条件、筛选、24:00提醒预填、分享预览与PNG保存、无横向溢出、个人通知存储字节不变。测试全程0模型、0外网业务请求、0生产写入。

分享模块无新依赖，独立懒加载，原始约8.4KB、gzip约3.9KB。900×1320画布上限单份像素缓冲约4.53MiB，不代表整个浏览器内存；生成后释放，预览URL关闭/换页回收。长内容完整分页，最多8页，超限明确要求简洁版。

Android包需由本轮CI构建，以交付清单确认签名、网页资源和发布结果；浏览器检查不等于安卓真机保存、权限或提醒送达验证。
