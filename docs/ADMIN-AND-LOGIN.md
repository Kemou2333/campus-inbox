# 管理后台与登录防护

管理页面位于后端 `/admin`，页面本身只提供登录表。账号列表、数量、用量、任务及其内容均由服务器鉴权后读取，不依赖前端隐藏按钮。

部署配置：

- `ADMIN_USERNAMES=kemou`：仅授权已有的该账号。默认空名单关闭后台；启动时固定已有账号 UUID，启动后新注册的相似名称不会获权。
- `ADMIN_ORIGIN=https://123.57.30.129`：管理页面的准确 HTTPS origin，同时加入登录允许来源。

后台只读，不提供删除账号、修改通知、重跑模型、发邀请码或更改权限功能。会话仅存在页面内存，退出或重载需重新登录；密码、会话密钥、密码散列、邮箱和原通知不会写入新的访问日志。页面使用独立 CSP nonce，禁止外部脚本；仅允许产品自身 GitHub Pages 域的只读通知预览 iframe。简版原文和结果以纯文本插入。

## 内容与统计边界

作者通过已鉴权的只读后台直接查看服务器已经保存的数据，不再提供“允许作者查看”的可选勾选，也没有按旧许可字段或三十天期限隐藏任务内容。旧数据库字段兼容留存，不重写原文、结果或用户进度；旧客户端带来的布尔字段被兼容接收但不再决定后台权限。

概况首屏展示今日整理量、整理成功／失败、账号数和处理中数量，近十四天趋势按上海时间的提交日期分组。成功表示 AI 结果已保存，不代表用户完成了现实事项；缓存复用计入整理请求，未知历史指标不补造。

账号和任务／通知列表只提供数量、标题、时间、状态与用量，正文与完整结果按需打开。账号行的“整理”查看已保存的 AI 初始任务快照；“通知”查看该账号当前云同步记录，包括导入记录、后续修改、完成／跳过状态、笔记与原文。删除标记不会作为当前通知重新展示。未上传的本机草稿、附件文件和仅在设备上的编辑不在后台。

所有账号、任务和通知 API 继续在服务器核对管理员会话、准确用户名与启动时固定的已有账号 UUID；普通账号不能通过指定别人的编号取得数据，也不能修改后台数据。登录邮箱、密码散列、会话密钥和验证码答案不进入后台数据响应。正常关于说明披露维护访问范围，不新增批准弹窗或替代许可选项。

结果是持久保存的初始结构化快照，用户后续编辑以普通通知同步空间为准。旧任务未记录逐条模型/缓存/Token 指标时显示未知，不能当作零次调用。每日费用是服务内部保守估算，不是供应商账单。管理员列表每页 50 个账号、20 条任务或云通知；每个管理员每分钟最多 60 次读取。

实际通知预览复用产品 React 组件，通过静态 URL `https://kemou2333.github.io/campus-inbox/admin-preview.html` 载入。后台只在 iframe 发出 ready 且来源和窗口均匹配后，将当前选择的通知对象以 `postMessage` 传到准确的 GitHub origin；不传会话密钥、用户名或密码，不把正文放进 URL。预览页反向核对固定管理员父域和父窗口，不访问登录、同步、存储或模型；只读展示保留逐项展开、原文查看。退出、切换视图或收起会移除 iframe 和所选数据；预览不可用时仍可展开简版／JSON。

## 登录协议

`POST /auth/options` 返回 `imageCaptchaEnabled: true`。

`POST /auth/challenge`：

```json
{"purpose":"login","clientId":"浏览器生成的随机 UUID"}
```

`purpose` 可为 `login`、`register`、`email`，回复 `id`、PNG `image`、`expiresAt`、`retryAfterSeconds`。图片不带答案文本。客户端编号须为 24–64 个字母、数字、下划线或短横线。

密码登录、邀请注册和邮件发验证码时附加：

```json
{"captcha":{"id":"服务返回的 id","answer":"四位数字"}}
```

验证码绑定准确的来源、IP 与用途，五分钟过期；一次成功即消费，五次猜错作废。只在独立测试中允许显式 `imageCaptcha:false`，生产入口没有关闭验证码的环境开关。

刷新限制：客户端十五秒冷却、每分钟十次；共享校园 IP 每分钟六十次、每小时三百次。限制计数持久保存；更换客户端编号不能绕过 IP 限制。

密码尝试限制：每个 IP 每分钟十次／每小时一百次，每个账号每分钟五次／每小时二十次，邮件与用户名别名共享账号预算。滚动窗口防止卡整分钟边界集中尝试，限制计数在密码派生前提交。未解出图形验证码的请求只计网络次数，不耗尽被点名账号的密码预算，以免轻易锁住他人。未知账号与密码错误回复相同；限制不会永久锁住账号。既有邮件发送、代码验证、邀请码及 AI 额度限制继续生效。

只有本机反向代理提供的单个合法 `X-Real-IP` 才作为客户 IP；公网直接传该头、列表或非法地址不会获信任。反向代理应监听 HTTPS，将 `/admin` 转到本机后端；后端默认仅监听 `127.0.0.1`。

错误代码：`AUTH_CAPTCHA_REQUIRED`、`AUTH_CAPTCHA_INVALID`、`AUTH_CAPTCHA_RATE_LIMIT`、`AUTH_RATE_LIMIT`。限制响应携带 `retryAfterSeconds`，客户端应显示等待且不自动反复请求验证码。
