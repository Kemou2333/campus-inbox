# Note Inbox 限额标准

当前运行值请在维护后台打开 **限额标准**，也可下载该页的 JSON。这里只提供同一实现导出的默认基线；部署配置可能覆盖全站整理次数、每日预算、思考模式和邮箱开关。

**本次没有放宽任何额度。** 滚动窗口按每条记录到期释放；上海自然日按北京时间零点重置。邮件日限额与兼容注册的不同窗口见各行说明。

## 先看这几项

- 整理：每账号5次/五小时、20次/三天；同IP5次/五小时；全站50次/上海日。
- 提问：每账号5次/五小时、15次/三天；同IP5次/五小时；全站40次/上海日。
- 两类共用每日3元的保守预算；达到任何一个上限就会停止新的付费调用。预算不是模型平台账单。
- 安卓主下载：每日预留200 MB，同IP每小时5次且同时1条，单条2 MB/秒；每次需完成四位图形验证码。

## 维护规则

1. 先记录旧值、新值、适用范围和时间窗口，不用一句“每日上限”代替完整口径。
2. 区分待调整、已实现、已发布和已验证；未上线的配置不能标为已生效。
3. 每次修改同步更新 [限额变更记录](LIMITS-CHANGELOG.md)，登记生效时间与部署版本。
4. 上线后读取后台 JSON 核对实际值；保留旧快照，不删账本、重置用户次数或启动第二份独立计数。
5. 后台目前只读，不提供未设边界的改值接口；不会因为查看或下载清单改变任何限额。

## 其他边界

- 兼容站点迁移仅用于旧来源到原阿里云的临时客户端加密接续，新域名主站不使用它。现有上限：单份及单IP暂存128 MiB、全站256 MiB；同时传输请求全站4/IP2；IP每分钟400请求、每小时10次创建，IP最多2份、全站最多8份；初始化60秒超时，上传后续期15分钟。它不等于普通账号云同步。
- SMTP单次发送最长10秒、OAuth令牌请求4秒；这些是失败等待时间，不是可用次数。
- 传输层、硬盘和代理软件自身限制不属于本应用的日下载账本；200 MB不能当作服务器套餐余额。

当前基线条目数：86。机器快照见 [limits-defaults.json](limits-defaults.json)。
