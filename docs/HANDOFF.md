## AI 接口（核心）

请先读 `AI-CONTRACT.md` 与 `analysis.schema.json`。

`worker/prompt.mjs` 是唯一实际运行的 System Prompt 来源。Worker 请求 Chat Completions 兼容服务：system=该提示词，user=JSON.stringify({notice})，默认 JSON object 模式；实际提供商和模型尚未指定。

网页请求 POST `/analyze`，正文 `{notice:"原文"}`。响应必须是固定对象，不是 Markdown，也不是代码块；tasks 是字符串数组。网页安全地把字段转换为卡片和内部任务对象 `{text,completed}`。原文、ID、创建时间、完成状态由前端生成，不让模型返回。

信息映射：title/summary→通知内容；deadline/deadlineText→主截止条；timeline→多个时间节点；tasks→复选清单；materials/warnings→材料及注意；originalText→原文折叠区。

只有完整年份、月日和时分才转 ISO。未写年份不能假定2026；只有日期不能补23:59；活动开始不能充当提交截止。缺失字段语义用 null/[]/空字符串，详细规范在提示词。
