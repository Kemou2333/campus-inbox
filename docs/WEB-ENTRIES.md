# Note Inbox 名称与网页入口

中文品牌“拾笺”，英文品牌“Note Inbox”。

- 主站：https://kemou.top:88
- GitHub备用网页：https://kemou2333.github.io/note-inbox/
- 源码、Issue、PR与正式Release：https://github.com/Kemou2333/note-inbox

日本节点提供网页、视频与安卓主下载入口，业务接口仍转到阿里云单一后台；账号数据和下载额度没有复制成两份。网站HTTPS使用88端口，同机443既有服务保持不变。未开通付费CDN。

真正的源码仓库由campus-inbox改名为note-inbox，保留原历史、Release、Issue和PR。原先仅作网页入口的仓库另存note-inbox-entry-backup-20261027。后续发布只维护主项目，不再维护旧Campus网页路径。

包名、存储键、签名、既有APK文件名与固定Ali更新接口保持兼容。下载校验仅接受同账号新旧仓库的精确版本资产地址，原Ali元数据继续返回旧APK认可的地址，新域名元数据使用Note Inbox地址。

不同来源的本机记录各自保存，登录同一账号后同步文字、笔记和进度，附件仍留本机。首次使用只显示一次AI隐私提醒，完整说明在设置→工具与帮助→隐私说明。
