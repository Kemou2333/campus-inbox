# 拾笺 · Note Inbox

粘贴大学群通知，让AI自动拆成待办卡片并形成个人待办清单，从此告别反复翻群消息。

[打开网页版](https://kemou.top:88) · [GitHub 备用网页](https://kemou2333.github.io/note-inbox/) · [安卓下载](https://kemou.top:88/downloads/android-v2.28.2/campus-inbox-2.28.2.apk)

刚上大一，班群、学院群和课程群每天都有大段通知。当时扫一眼觉得记住了，过两天真要办的时候，又得往上翻半天聊天记录找截止时间和详细要点。于是，我做了“拾笺 · Note Inbox”这个项目，想帮自己和身边的同学省掉反复翻群消息的麻烦。

现在平时看到课程、报名或交材料的通知，直接复制粘贴进来就行。服务器调用DeepSeek理出简短说明、截止时间、适用人群和具体步骤，直接生成一张清楚的待办卡片。列表收起时只显示标题和截止时间，还能顺手标个“重要紧急”等优先级，扫一眼就知道哪件事最急。

点开卡片后，各项要求按办事顺序排好，每办完一步就能打个勾，形成自己的待办清单；有补充安排可以贴张彩色便签写备注；卡片底部一直留着整条原通知方便随时核对，不用在聊天软件和待办工具之间来回切换。如果对通知细节有疑问，可以直接围绕这条通知向AI提问并查看原文依据；此外，还可以一键导出一张长图发给室友。

目前，网页和安卓APP都已经上线，打开就能体验，登录后还能在电脑和手机间双向云同步通知、笔记与办理进度。

## 实现概览

网页与安卓共用核心界面。服务端调用DeepSeek，以JSON输出模式返回整理结果，再校验字段、日期与内容边界。账号、同步和用量记录保存在同一后台，避免不同入口各算一套额度。[限额标准](docs/LIMITS.md)。

## 使用前须知

原文与提问会发给第三方DeepSeek处理，请勿输入身份证号、手机号等敏感信息。AI可能漏读或理解有误，重要事项请核对原通知。[隐私说明](docs/PRIVACY.md)。
