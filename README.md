# 拾笺 Inbox

把群里的长通知，变成清楚的待办和提醒。先看谁要做、什么时候做，再逐项展开具体要求。

拾笺，读作 **shí jiān**。原名「校园 Inbox」。

**[打开网页](https://kemou2333.github.io/campus-inbox/)** · [免注册体验示例](https://kemou2333.github.io/campus-inbox/?examples=1) · [下载 Android](https://github.com/Kemou2333/campus-inbox/releases)

## 能做什么

- **整理通知**：提取待办、时间、适用对象、材料和注意事项。
- **逐项办理**：展开步骤、勾选进度、记笔记；删错可在回收站恢复。
- **方便查找**：分类、搜索、收藏；示例置于个人通知之后，可一键隐藏。
- **按需查看**：设置年级、专业和身份；按学期设置换算教学周日期。
- **问这条通知**：针对原文提问，简短回答并附原文依据；每日最多5问。
- **分享清单**：在设备上生成带水印的图片，预览后保存。
- **创建提醒**：导出日历，或使用 Android 本地通知。
- **随时接着看**：同一账号同步通知文字、进度和笔记；支持导出备份。

## 怎么用

1. 粘贴一条或多条通知，点击「AI 整理」。
2. 收到「已提交」确认后，可以离开，稍后回来查看。
3. 展开某项要求，办完打勾，需要时添加提醒。

首次使用可跟随演示练习，无需调用 AI。公开示例已隐藏个人信息。

AI 可能遗漏或理解有误，重要事项请核对原通知。附件保存在添加它的设备，不自动识别或上传；跨设备同步以「已同步」状态为准。
